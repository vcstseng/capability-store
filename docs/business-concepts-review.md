# 十個企業領域：能力構想 prototype

本輪以使用者要求的想像設計出發，不搜尋 GitHub、不假設任何構想已實作，也不逐題解完 99 Problems。分類沿用十個企業領域；下方內容為設計假說。

共 10 個領域、30 個工作環節、60 個構想。GitHub 參考共 20 處放置、19 個不重複既有候選；未重新查核功能、相容性或可取得性。

類型按工作性質設計，不要求每類一個：Skill 為可重用分析／操作方法；Tool 為明確輸入輸出的計算／查詢；Agent 為有邊界的資訊整理與下一步判斷；Workflow 為步驟、交接與核准。這些標籤不是部署狀態。

## 銷售 / Sales

### 找對客戶

**客戶適配判讀 · skill · 構想**

把客戶需求與我們的產品條件逐項比對，列出符合、衝突與未知之處。

- 預期輸入：公司簡介、訪談筆記、產品適用條件
- 預期產出：適配說明與待補問清單
- 人工判斷：業務確認是否值得投入，不把資料缺漏當成不適合。

**潛在客戶優先排序 · tool · 構想**

依團隊自訂權重試算聯絡優先順序，讓排序理由可以重算。

- 預期輸入：客戶名單、需求訊號、評分規則
- 預期產出：優先名單、各項分數與缺資料標示
- 人工判斷：主管核准權重並處理策略客戶例外。

### 推進商機與報價

**訪談重點與承諾整理 · skill · 構想**

從會議內容分開整理客戶說過的需求、業務推測與雙方承諾。

- 預期輸入：會議逐字稿、Email、既有商機紀錄
- 預期產出：需求摘要、原文依據與下一次必問事項
- 人工判斷：業務確認摘要與承諾後才寫回 CRM。

**報價毛利與折扣試算 · tool · 構想**

比較折扣、數量與付款條件改變後的毛利及收款差異。

- 預期輸入：單價、成本、數量、折扣及帳期假設
- 預期產出：情境比較表與超出門檻的提示
- 人工判斷：主管決定讓利條件，工具不自動對外報價。

### 風險與商機檢討

**商機停滯調查員 · agent · 構想**

定期讀取商機進度與最近互動，找出承諾落空或決策流程不明的線索。

- 預期輸入：CRM 階段、會議紀錄、往來訊息
- 預期產出：附依據的風險摘要、待確認事項與行動草案
- 人工判斷：業務判斷是否追蹤，不能把沉默直接視為流失。

**每週商機檢討流程 · workflow · 構想**

收集異動→核對數字→整理風險→開會確認→追蹤行動，留下每週決定。

- 預期輸入：商機快照、目標、上週行動與負責人
- 預期產出：檢討議程、差異表、決策與下週行動
- 人工判斷：主管核准預測及資源調整，業務負責對外承諾。

## 行銷 / Marketing

### 理解受眾與訊息

**受眾需求與訊息拆解 · skill · 構想**

- 預期輸入：訪談、評論、問卷與產品定位
- 預期產出：需求情境、訊息方向與證據缺口
- 人工判斷：行銷確認受眾與主張，不把少數回饋當市場結論。

**創意素材簡報產生 · skill · 構想**

把活動目的轉成可交給設計與文案的素材需求，保留禁止宣稱與品牌限制。

- 預期輸入：活動目標、受眾、品牌規範、可用證據
- 預期產出：素材簡報、文案方向與檢查清單
- 人工判斷：品牌負責人核准內容後才製作或發布。

### 規劃與觀察活動

**通路預算情境試算 · tool · 構想**

比較不同預算分配的假設結果，顯示結果對轉換率與成本的敏感度。

- 預期輸入：通路成本、轉換假設、預算與投放限制
- 預期產出：情境表、敏感度與假設清單
- 人工判斷：行銷決定預算；歷史相關性不當成增量成效。

**活動異常觀察員 · agent · 構想**

追蹤素材與通路數據，整理異常變化以及需要人工查明的可能原因。

- 預期輸入：活動指標、素材版本、預期區間與更新紀錄
- 預期產出：異常摘要、受影響項目與調查建議
- 人工判斷：人員確認追蹤設定與原因後才停投或調整。

### 會員互動與檢討

**會員互動情境整理 · skill · 構想**

依購買節奏與聯繫紀錄整理可討論的互動情境，標示同意與頻率限制。

- 預期輸入：會員交易、互動紀錄、行銷同意與頻率政策
- 預期產出：互動情境草案與不可聯繫名單
- 人工判斷：行銷核准接觸對象與內容，不自動對會員發送。

**活動上線到檢討 · workflow · 構想**

簡報→素材審核→追蹤驗收→小範圍發布→成效檢討，逐步留下核准紀錄。

- 預期輸入：素材、指標定義、預算、核准與實際結果
- 預期產出：上線檢查、版本紀錄與可追蹤的檢討
- 人工判斷：發布與擴大投放需人核准。

## 財務 / Finance

### 分析成本與現金

**成本差異拆解 · skill · 構想**

把成本上升拆成價格、用量、效率與組合差異，列出需要查證的解釋。

- 預期輸入：標準成本、實際成本、產量與成本口徑
- 預期產出：差異橋接表、假設與查證清單
- 人工判斷：財務與現場確認歸因，差異不等於根因。

**現金缺口情境試算 · tool · 構想**

按收付款日期試算餘額，對延遲收款與突發支出做情境比較。

- 預期輸入：期初現金、應收應付、付款日期與情境假設
- 預期產出：現金走勢、缺口時間與敏感度
- 人工判斷：財務主管決定調度；工具不執行付款或借款。

### 檢視假設與獲利

**預算假設變動整理 · skill · 構想**

比對預算與實績，區分數字偏差、口徑變更與可能失效的營運假設。

- 預期輸入：預算、實績、指標定義與原假設
- 預期產出：偏差說明、待更新假設與補資料事項
- 人工判斷：預算負責人確認假設後再修正預測。

**獲利流失橋接試算 · tool · 構想**

把折扣、退貨、物流與通路費等影響拆開，對照產品和客戶組合。

- 預期輸入：交易明細、費用分攤規則與比較期間
- 預期產出：獲利橋接、影響排行與計算明細
- 人工判斷：財務核准分攤口徑，避免重複計入費用。

### 查證與核准

**財務異常查證助理 · agent · 構想**

根據異常數字追查相關紀錄，整理有證據的解釋與仍缺少的資料。

- 預期輸入：異常項目、交易紀錄、憑證與允許的查詢範圍
- 預期產出：可追溯的調查摘要與待覆核項目
- 人工判斷：財務覆核後才調整帳務或對外說明。

**發票核對到付款核准 · workflow · 構想**

收件→抽取欄位→核對訂單與收貨→處理例外→人工核准，保留差異。

- 預期輸入：發票、訂單、收貨資料、容差與核准規則
- 預期產出：匹配結果、差異清單與待核准案件
- 人工判斷：人員確認重複或不符案件，付款另需授權。

## 人資 / Human resources

**職務與履歷證據對照 · skill · 構想**

把職務需求拆成可觀察的證據，再整理履歷哪些內容支持或尚未交代。

- 預期輸入：職務需求、履歷與核准的評估標準
- 預期產出：證據對照與面談問題，不作錄取決定
- 人工判斷：招募人員確認標準與公平性，最終判斷由人負責。

**技能缺口訪談準備 · skill · 構想**

整理工作成果與自述技能的證據缺口，產生需透過訪談確認的問題。

- 預期輸入：職務能力要求、專案成果與自述經驗
- 預期產出：技能證據清單、未知項與訪談題目
- 人工判斷：主管與員工共同確認，不把提及技能等同熟練。

### 人力與發展規劃

**人力與工時需求試算 · tool · 構想**

把工作量與標準工時轉成不同人力配置情境，顯示假設與缺口。

- 預期輸入：工作量、工時、技能組合、班次與限制
- 預期產出：產能缺口、人力情境與敏感度
- 人工判斷：主管確認工時與勞動條件，不自動排定人事結果。

**學習路徑規劃助理 · agent · 構想**

依確認過的能力缺口，整理練習、資源和檢核點，追蹤學習證據。

- 預期輸入：能力目標、可投入時間、資源與成果回饋
- 預期產出：可調整的學習計畫與檢核問題
- 人工判斷：員工與主管共同選定目標，不保證課程能補齊能力。

### 到職與案件處理

**新人到職與交接 · workflow · 構想**

確認角色→安排帳號與訓練→指派交接→追蹤完成→收集問題。

- 預期輸入：職務、到職日、核准權限、任務與負責人
- 預期產出：到職任務表、未完成事項與交接紀錄
- 人工判斷：系統權限由負責人核准，不能因到職自動擴權。

**人事案件規範定位 · skill · 構想**

整理案件需要查哪些公司制度與適用規範，標示版本衝突及待專業確認事項。

- 預期輸入：案件概況、有效政策、適用地區與日期
- 預期產出：來源清單、待釐清問題與升級建議
- 人工判斷：HR 或法務決定處理方式，不以構想代替法律判斷。

## 採購 / Procurement

- 預期輸入：報價文件、欄位規格與單位對照

**商務條件差異整理 · skill · 構想**

把交期、保固、付款與運費條件的差異逐項列出，不只看單價。

- 預期輸入：多家報價、採購需求與核准條件
- 預期產出：條件差異、模糊條款與追問清單
- 人工判斷：採購與法務確認條款含義及談判底線。

### 比較成本與分單

**總採購成本試算 · tool · 構想**

把單價、運費、匯率與一次性費用換成同一口徑，試算不同數量。

- 預期輸入：已確認的報價表、匯率、數量與分攤假設
- 預期產出：可重算的成本比較與敏感度
- 人工判斷：採購確認隱藏成本與比較口徑，不自動選供應商。

**供應商分單情境比較 · tool · 構想**

在產能、最低量、成本與集中度限制下比較幾種訂單分配。

- 預期輸入：合格供應商、需求量、產能與限制條件
- 預期產出：分單方案、限制違反與成本比較
- 人工判斷：採購主管決定風險取捨及最終分單。

### 風險與採購流程

**供應商風險調查助理 · agent · 構想**

**詢價到採購核准 · workflow · 構想**

- 預期產出：版本一致的比較包與決策紀錄
- 人工判斷：對外詢問、承諾及下單依授權由人核准。
